# **App Name**: Lore Weaver

## Core Features:

- Campaign Management: Create, update, and manage RPG campaigns, including titles, descriptions, and default settings.
- Character and Entity Management: Create and manage characters, places, items, and monsters with detailed profiles and revision history.
- Narrative Thread: Create and manage narrative threads with forum-like posts and comment threads for collaborative storytelling.
- Cross-Reference Parser: Automatically parse and link mentions of characters, places, and items using a stable identifier system.
- User Authentication and Authorization: Secure user accounts with different roles (Admin, GM, Player) and API key support for external services.

## Style Guidelines:

- Primary color: Desaturated teal (#2E6B6B) to evoke a calm and immersive atmosphere.
- Background color: Jet charcoal (#0B1113) for the main page background.
- Accent color: Soft mossy green (#6F9B6F) to highlight key elements and interactive components.
- Headline font: 'Playfair' (serif) for an elegant and readable display of headings.
- Body font: 'PT Sans' (sans-serif) for clean and modern readability in body text.
- Incorporate subtle medieval-themed icons using a parchment rune accent color (#C2B59B) for borders and minor details.
- Use a card-based layout with frosted glass overlays (rgba(255,255,255,0.02)) for a modern and slightly translucent panel design.
