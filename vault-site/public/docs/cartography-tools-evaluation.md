## Watabou
Fuente https://watabou.github.io/faq.html y https://itch.io/t/3635229/export-import. City/Village/Neighbourhood exportan JSON de geometría emparentada; One Page Dungeon tiene otro esquema; Perilous Shores y Dwellings incorporaron exportación JSON posteriormente (https://watabou.github.io/news.html). Los generadores actuales no son open source en general; permiso de uso de mapas incluso en aventuras comerciales, no equivale a licencia para redistribuir el programa o vender mapas generados como producto aislado. Revisar condiciones de datos y automatización antes de integración productiva.

## Fantasy Town Generator
https://docs.fantasytowngenerator.com/useSettlements/export/ documenta SVG/PNG, GeoJSON en coordenadas internas de 1 unidad = 1 m, JSON/CSV de edificios/población. https://docs.fantasytowngenerator.com/useSettlements/simulation/ describe horarios, sueño, ocio, trabajos, recursos, acceso por tipo de visitante y capacidad de sublugares. Foundry integración de mapas, edificios, gente, facciones y hora documentada en https://docs.fantasytowngenerator.com/externalTools/foundry/; utiliza autorización de origen y acceso al asentamiento, no equivale a API pública libre.
Prueba Edge: página y formulario temporal accesibles sin cuenta. Opciones observadas: hamlet ~100, pueblo ~500, ciudades hasta ~25000 sin premium, humanos, polar, litoral y muralla. Intento de crear PocketDM test hamlet con opciones de muestra devolvió pantalla inicial de creación sin asentamiento accesible; no se descargó GeoJSON ni población, no se verificaron campos reales de horarios ni correspondencia de IDs. No se creó cuenta, no se compró plan. Licencia creativa de FTG pendiente de revisar: no se pudo leer su texto en web.
## Recomendación
Primero exportación manual válida de SVG + JSON del mismo mapa Watabou y prueba de importación geométrica. Adaptadores separados por formato y versión. Guardar fuente, semilla, parámetros, hash, sistema de coordenadas, transformación, IDs estables; no inferir metros en Watabou sin verificar escala. Polígonos como regiones seleccionables, enlaces a nodo de edificio, distrito y entradas; calles/rutas validadas, no unir centroides atravesando muros. Geografía regional de Perilous Shores como mapa separado, coherencia de costas/caminos entre escalas por aprobar. Dwellings/One Page Dungeon para interior vinculado al edificio. FTG como opción de referencia demográfica y horarios; antes de decidir, obtener exportaciones reales y verificar licencia y correspondencia de geometría a habitantes. PocketDM conserva autoridad de ficha Mythras, relaciones, presencia/agenda, conocimiento, consecuencias y roleo LLM; no importar reglas D&D ni reacciones de NPC automáticas. No generar una ciudad en cada herramienta e identificar edificios arbitrariamente entre ellas. No se modificó el atlas publicado ni se importaron datos falsos.
