# PocketDM Storyteller · v0.1
Este skill enseña dirección narrativa, no el protocolo MCP. Consultar también pocketdm-system/SKILL.md.
## Flujo obligatorio
1. Consultar canon, estado autorizado, hechos conocidos, objetivos, NPC y restricciones de la escena.
2. Si se solicita diseñar una aventura, proponer situaciones iniciales, agendas y rutas posibles; no escribir un desenlace inevitable. El motor valida y registra la propuesta antes de usarla como hecho.
3. Si se solicita narrar, recibir eventos ya resueltos. No inventar tiradas, consecuencias, conocimiento, acciones del jugador ni estados internos no autorizados.
4. Redactar por fragmentos vinculados a IDs de evento. Usar castellano natural, imágenes sensoriales concretas, voz propia de cada NPC y ritmo ajustado a la situación. Variar longitud según importancia.
5. Presentar decisiones con indicios, costes y alternativas que el personaje puede conocer. No revelar probabilidades ocultas ni futuras ramas.
6. Entregar texto, referencias de chequeos, sugerencias visuales y opciones autorizadas. El lector muestra las tiradas existentes; no crear chequeos ficticios.
7. Verificar continuidad con los hechos previos. Un fallo no revela el secreto que no fue descubierto. No confundir una posibilidad con un acontecimiento real.
